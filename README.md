# LastDay · 裁员补偿谈判助手

帮被裁员工算清经济补偿（N / N+1 / 2N）、看懂法律依据、避开 HR 常见坑的**纯前端**网页工具。

## 功能

- **三步向导**：① 问答式解除定性（自动判定 N / N+1 / 2N）→ ② 月均工资基数构成（逐项说明什么算、什么不算）→ ③ 测算结果 + 法条依据 + 自动生成谈判话术/异议函
- **工资流水粘贴解析**：每行一条，自动提取金额并按关键词归类，可逐条修正后一键应用
- **差额对比**：法定应得 vs 公司方案，自动算出可能被少算的金额
- **坑点自查**：24 个高频被坑点打勾排查
- **法条速查**：15 部核心条文原文摘录 + 白话解释
- **隐私**：无后端、无埋点，所有数据只存在浏览器 localStorage

## 运行

无需构建。任选其一：

# 方式一：直接双击 index.html（file:// 协议可正常使用）

# 方式二：本地起服务

# 浏览器打开 http://localhost:8080
```

```

## 计算口径速记

- **N**：每满1年=1个月工资；余≥6个月按1年，<6个月半个月（劳动合同法47条）
- **基数**：离职前12个月**税前应发**平均，含奖金、津贴补贴、加班费（实施条例27条）；超当地社平3倍按3倍封顶且≤12年
- **+1**：代通知金按上一个月工资（实施条例20条）
- **2N**：违法解除赔偿金（87条），与 N/N+1 不叠加
- 年假未休：额外200%日工资；年终奖：按当年在职天数折算

## 免责声明

内容依据《劳动合同法》等公开法律法规整理，仅供参考，**不构成法律意见**。各地裁判口径有差异，重大争议请咨询当地劳动仲裁机构或专业律师。
